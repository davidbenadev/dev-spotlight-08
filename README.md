# David Benavides Portfolio

Actúa como un desarrollador web experto y construye un portafolio personal estático usando Vite, React, Tailwind CSS y componentes de UI minimalistas.

Directrices Visuales:

El diseño debe tener una estética "Dark Mode" inspirada en Spotify.

Usa una paleta estricta: Negro para los fondos principales, grises para separar secciones o tarjetas de contenido, y un verde neón/Spotify para acentos, iconos, bordes activos y botones principales. El diseño debe ser muy limpio, sin bordes pesados ni sombras exageradas.

Contenido y Secciones:

Navegación: Un header fijo y transparente que se difumine al hacer scroll, con enlaces a las secciones: About, Experience, Projects, y un botón de "CV".

Hero: Presentación para "David Benavides", destacando el rol de "Senior AI Fullstack Engineer".

About Me: Un contenedor minimalista con texto sobre la pasión por el desarrollo de software y la integración de inteligencia artificial.

Experience: Crea un componente interactivo o visualmente claro de línea de tiempo (timeline). Añade datos de prueba relevantes: Desarrollo de aplicaciones fullstack, automatización de procesos con IA y liderazgo de equipos técnicos.

Portafolio: Una sección con un grid layout para mostrar proyectos. Que las imágenes sean placeholders grises limpios.

Redes: Un footer muy limpio con botones/iconos de GitHub y LinkedIn.

Requisitos técnicos: El proyecto debe ser completamente frontend. No incluyas bases de datos ni backend. Todo el enrutamiento debe ser manejado en la misma página para que sea 100% estático y fácil de desplegar en plataformas gratuitas como GitHub Pages o Netlify.
